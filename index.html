PROJECT 02

Flood Risk Detection

A Java desktop mini-project exploring flood-risk zones and water paths through graph-based terrain modelling.

JavaJavaFXGraphsDijkstra’s algorithm
Explore project ＋

Flood Risk Detection — Graph-Based Terrain Analysis is an educational Java / JavaFX desktop project. It samples an image into a grid, uses grayscale brightness as a relative elevation proxy, and connects neighbouring cells as a weighted graph. Flow accumulation and threshold-based floodplain rules produce a colour-coded risk overlay. Selecting a cell traces a weighted path to a low boundary outlet using Dijkstra’s algorithm. Custom lists, a queue and a min-heap support the graph operations. The model demonstrates algorithms rather than validated real-world flood forecasting.

PROJECT 03

First Touch

A football talent discovery project spanning a web app, mobile app and supporting API.

ReactViteJavaScriptReact NativeExpoNode.jsExpressMySQL
Explore project ＋

First Touch aims to help local football players gain exposure and help recruiters discover talent. The source includes separate web experiences for players, coaches, recruiters and administrators, with areas for profiles, training, progress, player discovery and shortlists. A React web app and Expo / React Native mobile app are supported by a Node.js / Express API with MySQL integration. Some screens still use mock data or placeholder player identities, so this is presented as a school project in development rather than a fully verified live service.
